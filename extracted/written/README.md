## Purpose

The site presents verified education, professional experience, technical interests, and selected personal interests for internship, recruiting, and technical-review audiences.

## Technology

- JavaScript
- GitHub Pages

No backend, database, login system, analytics tracker, or external data collection is required.

Public-facing portfolio content is derived from the author's professional resume and the project's `content-notes.md`. Private contact information is intentionally excluded.
