# Problem statement

Customize the instructor-approved static portfolio template into a professional public portfolio for Christian Benjamin Namath Heiney. The site should present verified education, professional experience, technical interests, and selected personal interests in a clear format suitable for internship/recruiting reviewers.

# Intended audience

- Internship and early-career hiring reviewers
- Software engineering / AI / data-science reviewers
- Finance and financial-risk technology professionals
- Academic reviewers interested in an AI/ML graduate student's technical background

# Acceptance criteria

1. The landing page displays Christian Benjamin Namath Heiney and a concise professional role related to Asset Liability Management and financial analytics.
2. The portfolio contains at least two substantive sections describing professional experience and education, using only verified resume information.
3. Navigation links move to the intended portfolio sections without broken links.
4. The page remains readable and usable on a narrow mobile viewport without horizontal scrolling or overlapping content.
5. No private contact information or placeholder/template identity remains in the published site.
6. External/project links, if included, use real destinations only; no invented URLs are presented as factual links.
7. Keyboard navigation is usable and images have meaningful alternative text or are explicitly decorative.
8. The browser console contains no unexplained errors during normal page use.

# Constraints / non-goals

- Static front-end only.
- No backend, database, login system, analytics tracker, or external data collection.
- Do not invent education, work history, awards, certifications, project history, links, or technical skills.
- Preserve the starter repository's required license and attribution.
- Do not publish the resume's street address, phone number, or personal email address.
- Preserve the existing layout structure where practical; make only focused content, styling, and small front-end corrections.
- Keep the site accessible and usable on mobile screens.
